# Учёт обслуживания парка дронов

Веб-приложение для контроля технического обслуживания парка дронов разных типов:
наработка (лётные часы и циклы), запчасти с назначенным ресурсом, журнал полётов
и журнал обслуживания. Поддерживается импорт данных из таблиц CSV/Excel.

## Возможности

- Учёт дронов разных типов: бортовой номер, тип/модель, серийный номер, статус.
- Журнал полётов — наработка (часы) считается автоматически как сумма записей
  плюс начальная наработка на момент начала учёта.
- Учёт запчастей: назначенный ресурс (в часах и/или циклах), установка/снятие
  с дрона, автоматический расчёт наработки и остатка ресурса, индикация
  «требует внимания» / «ресурс исчерпан».
- Трекеры: статус активации (не активирован / активирован / приостановлен) и
  сроки договоров на использование, с индикацией истекающих и истёкших
  договоров на дашборде.
- Журнал работ по ТО (осмотры, ремонты, замены) по каждому дрону.
- Импорт данных из CSV/XLSX файлов (дроны, полёты, запчасти, трекеры) — с
  шаблонами таблиц и отчётом об ошибках построчно.
- Минималистичный интерфейс без лишних элементов.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

Приложение будет доступно на `http://localhost:5000`. База данных SQLite
создаётся автоматически в `instance/fleet.db` при первом запуске.

## Импорт из таблиц

В разделе «Импорт из таблиц» можно скачать шаблоны CSV для всех типов данных
(дроны, полёты, запчасти, трекеры) и загрузить свою таблицу — заголовки столбцов
распознаются независимо от регистра. Обязательные связи (полёты и запчасти
привязываются к дрону по бортовому номеру) проверяются при импорте; строки
с ошибками пропускаются, а не прерывают весь импорт, и выводятся в отчёте.

## Сборка .exe для Windows (запуск без консоли, сразу в браузере)

Собирать нужно на Windows-машине — PyInstaller не кросс-компилирует из
Linux/macOS в Windows.

1. Установите Python 3.11 или 3.12 (не самая новая версия — так надёжнее
   собираются бинарные зависимости вроде pandas).
2. В папке проекта запустите:
   ```
   build_exe.bat
   ```
   Скрипт сам создаст виртуальное окружение, поставит зависимости и PyInstaller,
   соберёт `dist\TO-Maintenance.exe`.
3. Готовый `TO-Maintenance.exe` можно переносить и запускать на любом Windows
   ПК без Python — двойной клик поднимает сервер на `127.0.0.1:5000` и сам
   открывает браузер. База данных (`instance\fleet.db`) создаётся рядом
   с `.exe` и сохраняется между запусками.

Если после первой сборки хочется скрыть консольное окно — в `build_exe.bat`
уже указан флаг `--windowed`; если наоборот нужно видеть окно консоли для
отладки ошибок запуска, уберите этот флаг и пересоберите.
